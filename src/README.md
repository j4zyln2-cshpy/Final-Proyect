# SRC

Esta carpeta contiene el núcleo lógico y los módulos del videojuego **Kingdom Defense 1D**, organizados según el principio de separación de responsabilidades.

## Estructura de Carpetas

* `core`: principalmente tiene directores globales (sonido y dibujos) y la configuración y rutas base del juego.
* `entities`: este contiene las clases de las entidades del juego (proyectiles, defensores, enemigos, torres, hechizos).
* `scenes`: contiene las escenas principales, tanto para el juego como para el mapa
* `ui`: contiene la clase principal para la interfaz del juego
